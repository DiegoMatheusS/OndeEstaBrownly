ONDE ESTÁ BROWNLY? — versão 1.0

Projeto 100% estático (HTML/CSS/JavaScript/SVG), pronto para GitHub Pages.

COMO ABRIR
1. Extraia o ZIP.
2. Abra index.html no navegador, ou use Live Server no VS Code.
3. Para publicar no GitHub Pages, envie TODO o conteúdo desta pasta para a raiz do repositório.
4. Em Settings > Pages, escolha Deploy from a branch > main > /(root).

O QUE JÁ TEM
- Personagem original Brownly: homem negro de meia-idade, gorro de duende verde, camisa listrada azul/branca, kilt escocês e lápis fino usado como bengala.
- 3 níveis: Fácil, Médio e Hard.
- 15 mapas por nível (45 no total).
- Quantidade de fases: 3, 6, 9, 12 ou 15.
- Ranking local separado por nível + quantidade.
- Música procedural original (Web Audio) e efeitos.
- Menu animado.
- Referência de Brownly na lateral exatamente na pose escondida.
- Zoom 100% a 300%, roda do mouse, botões, pinça no celular e arraste com zoom.
- Imagens não arrastáveis e cursor normal na área do personagem.
- Avanço apenas ao clicar na hitbox correta.

ARQUIVOS
index.html — página principal
styles.css — visual e responsividade
game.js — lógica do jogo
phases.js — cadastro dos 45 mapas e coordenadas
assets/characters — 4 poses de Brownly
assets/maps — 45 mapas SVG originais

OBSERVAÇÃO
Os mapas são ilustrações vetoriais originais geradas especificamente para este protótipo e não usam imagens ou personagens de Onde Está Wally.
